# Crews Bot Dashboard guide

## Tasks
View saved status, next steps, evidence and outputs. Refresh reloads saved records; it does not check live task progress. Your agent verifies completion. Removing a task from the dashboard does not stop execution or delete output.

## Workflows
Choose Prepare to run to use an existing method. Workflow names, descriptions, categories and contents remain in their original language. All workflows you create or import are kept alongside the built-in sample.

## Getting started
Try a sample task: Three-step plan, describe a workflow, or import a workflow. Saving a method does not start a task. Edit the prefilled prompt, copy it, and send it to your agent. Edits apply only to this request.

## Language
The interface uses English. Replies and deliverables follow the user's language; English prompts do not require English output. Personal tasks and workflows are not translated or overwritten.
