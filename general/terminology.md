# Terminology

Interface vocabulary. The interface is English with no language switch; personal content is never translated.

| Term | Meaning |
|---|---|
| Dashboard | The local view of saved task records and workflows. |
| Task | A specific piece of work, independent of where it runs. |
| Workflow | A reusable method defining inputs, steps and outputs. Running it creates a task. |
| Coordinator | The agent conversation that arranges, tracks and verifies tasks. |
| Getting started | Sample task, workflow creation and workflow import. |
| Prepare to run | Review the prompt for an existing workflow before sending it. |
| Copy prompt | Copy the edited prompt; does not execute a task. |
| Not started | Recorded as not started. |
| In progress | Recorded as running. |
| Pending | Awaiting review, input or another next step. |
| Completed | Output verified and completion recorded. |
| Needs verification | Current status requires verification; shown when present. |
| Cancelled | Explicitly cancelled; shown when present. Not the same as removal from the dashboard. |

Navigation: Tasks / Workflows / Getting started. Getting-started actions: Try a sample task: Three-step plan / Describe a workflow / Import workflow.

Dates and times use local time in the format 24 Nov 2026, 14:05, without a timezone suffix. Snapshot updated is the snapshot generation time, not each task's last verification time.

Chat and Bot describe host-specific ways of running work, not separate core objects.
