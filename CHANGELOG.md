# Changelog

Versions use dates: `YYYY.MM.DD.N`.

## 2026.11.25.1

First public release.

- Coordinator method, workflow authoring guide and getting-started guide.
- Local dashboard: tasks, workflows and getting started.
- Sample workflow: Three-step plan, covering plan, review, pause and next-day continuation with fictional materials.
- Installer with fixed versions, separate workspace, update and rollback. Works without a GitHub account for public repositories.
- Host support matrix: Codex fully supported; Cursor, Claude Code, Grok Build, Hermes and OpenClaw in development.
